## Development

Use Node.js 24.15 or newer in the 24.x series (or Node.js 26+) and npm. To override the public `VITE_` settings,
copy `.env.example` to `.env` and edit it. Existing `REACT_APP_` settings should use the `VITE_` prefix.

```shell
npm ci
npm run dev
```

The report reads data from the `<script id="state" type="application/json">` element in `index.html`.
To load a local `state/state.json` into the development page, run `npm run load-state` before starting Vite.
The JSON uses the same `config`, `createdAt` and `servicesCoverage` fields generated by `swagger-coverage-tool`.
Keep the source `index.html` state element empty when committing changes.

Run the same checks as CI with:

```shell
npm run lint
npm run typecheck
npm run test:coverage
npm run build
```

Tests use Vitest and React Testing Library. Coverage must reach 90% for statements, branches, functions and lines.
Use `npm run test:watch` while working on a test.

## Build

`npm run build` writes `build/index.html` with JavaScript and CSS inlined. The report can be opened directly in a
browser after `swagger-coverage-tool` embeds its data; no separate JavaScript or CSS files are required.
The `state` script element is preserved for the Python backend to inject the report JSON.

To refresh the backend template, build this frontend in the backend's `submodules/swagger-coverage-report` directory,
then run `swagger-coverage-tool copy-report` from the backend root.
